# 🛠️ Troubleshooting Logs (트러블슈팅 기록소)
> 개발 중 마주한 에러, 문제 상황과 이를 해결한 과정을 기록하고 기억하기 위한 오답 노트입니다


> ## 📌 기록 원칙
1. **문제 상황 (Issue):** 어떤 에러가 발생했는지, 어떤 현상이 있었는지 명확히 기록합니다.
2. **원인 분석 (Cause):** 왜 이런 문제가 발생했는지 파악한 원인을 적습니다.
3. **해결 방법 (Solution):** 어떻게 문제를 해결했는지 코드나 설정 방법을 공유합니다.
4. **회고 (Retrospective):** 재발 방지를 위해 새롭게 알게 된 점이나 주의할 점을 남깁니다.
